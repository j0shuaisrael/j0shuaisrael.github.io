Setup — run JoyCaption on your Mac (once)

The model is JoyCaption Beta One (still the latest release — there is no Beta Two or 1.0 yet). The full-precision model is 16 GB, so this setup uses the IQ4_XS quantized build: 4.48 GB, the best quality for its size, and it fits on an 8 GB Mac. The step-up is Q4_K_M (4.92 GB) if you have 16 GB or more; the smallest is Q2_K (3.18 GB).

1. Install llama.cpp (the runner — it uses your Mac’s GPU cores through Metal):

brew install llama.cpp

2. Download these two files into one folder:

Model, IQ4_XS (4.48 GB):
llama-joycaption-beta-one-hf-llava.IQ4_XS.gguf

Vision projector, required (0.88 GB):
llama-joycaption-beta-one-llava-mmproj-model-f16.gguf

3. In Terminal, from that folder, start the server:

llama-server -m llama-joycaption-beta-one-hf-llava.IQ4_XS.gguf --mmproj llama-joycaption-beta-one-llava-mmproj-model-f16.gguf -c 4096 --port 8080

Leave that Terminal window running. Come back here, hit “Check again”, and caption away. The server only listens on your own computer (127.0.0.1), so nobody else can reach it. If your install only has the newer llama command instead of llama-server, the same flags work with llama serve in place of llama-server.

Model: fancyfeast/llama-joycaption-beta-one-hf-llava (Apache-2.0). Demo that ran out of free quota: joy-caption-beta-one on Hugging Face.

Images are sent only to your own computer (localhost) — never to this website or any other server. JoyCaption Beta One is free, open weights, and uncensored by design: equal coverage of SFW and NSFW concepts.
