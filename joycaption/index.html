JoyCaption captions

Free, uncensored image captions from JoyCaption Beta One. The model runs locally, so there is no queue and nothing is uploaded to any website. This page is the front end: it sends each image to a local server and displays the caption the model returns.

Setup — run JoyCaption locally (once)

Model: JoyCaption Beta One (current release). The full-precision model is 16 GB, so this setup uses the IQ4_XS quantized build (4.48 GB), a balance of quality and size that fits on a machine with 8 GB of memory. Q4_K_M (4.92 GB) is the higher-quality option for machines with 16 GB or more; Q2_K (3.18 GB) is the smallest.

Model: fancyfeast/llama-joycaption-beta-one-hf-llava (Apache-2.0). Online demo: joy-caption-beta-one on Hugging Face.

Images are sent only to the local computer (localhost) — never to this website or any other server. JoyCaption Beta One is free, open weights, and uncensored by design: equal coverage of SFW and NSFW concepts.
