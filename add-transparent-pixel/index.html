Add a transparent pixel

Reddit converts opaque PNGs to JPEG. A PNG with any transparent pixel keeps its alpha channel, so Reddit leaves it as a PNG. By default this page sets one single pixel — the very last pixel of the image, the bottom-right corner — to transparent, and the image stays exactly the same size. If one pixel feels too small, tick the box below to add a whole transparent row under the image instead. Everything runs in your browser; nothing is uploaded.
